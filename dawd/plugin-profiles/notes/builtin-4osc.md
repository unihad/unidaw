4OSC — simple subtractive synth (4 oscillators → filter → amp, 2 LFOs, 2 mod envelopes, built-in FX).

Pitfalls:
- Out of the box it plays a plain sine: set settings first — Wave 1..4 (sine, triangle, sawUp, square, noise, none), Filter Type (lowpass … — 'none' means filter parameters do nothing), Distortion/Reverb/Delay/Chorus On (all off: their amounts do nothing until on).
- Pulse Width only acts on a square wave; Detune/Spread act on the unison voices — raise Unison (settings) above 1.
- Oscillators 2–4 start with Wave none (silent) — set their Wave to use them; Level 1..4 per oscillator.

Recipes: bass = Wave 1 sawUp + Filter Type lowpass, Filter Freq low, short Amp Release; pad = 2–3 detuned saws, Unison 3–4, slow Amp Attack, Chorus/Reverb on.
