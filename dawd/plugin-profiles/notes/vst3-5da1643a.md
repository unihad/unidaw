sfizz — SFZ sampler for multisampled instruments (velocity layers, round robins, release samples).

- Instruments are .sfz files in ~/sfz (also ~/.local/share/sfz, ~/Documents/SFZ): listPresets {plugin} lists them (category = folder), loadPreset {plugin, name} or setPluginFile {plugin, file} loads one.
- Installed: Salamander Grand Piano V3 (Yamaha C5, 16 velocity layers, CC-BY 3.0) — the Retuned variant is stretch-tuned.
- Without a file it plays a plain sine (loud) — always load an instrument first.
