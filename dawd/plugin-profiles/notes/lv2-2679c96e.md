x42-eq (fil4) — simple, clean parametric EQ: high-/low-pass, low/high shelf and four bells, all in dB and Hz.

- Each section has its own switch: Highpass, Lowpass, Lowshelf, Section 1–4, Highshelf must be On, otherwise the frequency/gain controls do nothing.
- Gain (overall, dB), Frequency n / Bandwidth n (octaves) / Gain n (±18 dB) for the bells; Highpass Frequency 30–100 Hz removes rumble.
- Good first choice for tone shaping; LSP Para EQ for more bands or steeper slopes.
