MDA Image — stereo width and mid/side: level and pan of the centre (mid) and the sides separately.

- All parameters are 0–1 without units. S Width = side level: 0.5 = mono, 0.75 = unchanged (default), 1 = wider (measured on stereo noise: correlation 0 → −0.6, +4 LU); below 0.5 the sides come back with flipped polarity (L/R swapped), 0.25 measures like 0.75.
- M Level works the same for the centre: 0.75 = unchanged, 0.5 = no centre (only the sides, correlation −1) — lower it a little to widen without touching the sides.
- A mono source stays mono: Image only scales what is already different between L and R. For width from a mono part use Stereo Balance Control (delay one side) or double the part on a second track, panned L/R.
- Mode: dawd sets 0.75 on addPlugin — that is plain left/right in and out, what everything above describes (the plugin labels it "Decode from MS (input channels reversed)"). The plugin's own default 0.0 (labelled "Stereo image adjustment", also 0.25 and 0.5) treats the input as side (left) and mid (right): a mono source ends up almost only on the left (+17 dB). Keep 0.75 unless you build an M/S chain on purpose. Output trims the level (MS-encoded material may need about 6 dB).
- The measured profile uses a mono test signal: S Width and S Pan show no effect there — they only act on what differs between L and R.
