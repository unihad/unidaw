LSP Multiband Compressor Stereo x8 — up to 8 bands with own threshold/ratio each; master or bus control, de-essing, taming boomy lows.

- 246 parameters: per band the same set as LSP Compressor (threshold, ratio, attack, release, makeup) plus split frequencies and band on/off. Use pluginInfo with paramQuery (e.g. "band 1", "split") instead of listing everything.
- Gains are linear factors, not dB (1 = 0 dB, 0.5 ≈ -6 dB, 2 ≈ +6 dB); thresholds likewise (0.25 ≈ -12 dB, 0.1 = -20 dB) — listParameters shows them only in the text (real is just 0–1), so set them by text: setParameter {name, text: "0.5"}.
- Start with 3 bands (low/mid/high), gentle ratios (1.5–3); check with analyze / compareReference that the tonal balance moves the way you want.
