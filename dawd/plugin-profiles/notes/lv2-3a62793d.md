LSP Compressor Stereo — full-featured compressor (bus, drums, glue, vocals).

- Gains are linear factors, not dB (1 = 0 dB, 0.5 ≈ -6 dB, 2 ≈ +6 dB); thresholds likewise (0.25 ≈ -12 dB, 0.1 = -20 dB) — listParameters shows them only in the text (real is just 0–1), so set them by text: setParameter {name, text: "0.5"}.
- Core: Attack threshold (= threshold), Ratio (1–100), Attack time / Release time (ms), Knee, Makeup gain. Dry/Wet balance (%) for parallel compression.
- Sidechain mode Peak (fast, drums) or RMS (smooth, buses/vocals); Sidechain lookahead (ms) catches transients. High-/Low-pass filter mode on the sidechain keeps bass from pumping the whole mix.
- Compression mode Down = normal; Up/Boost raise quiet parts — leave on Down unless you want upward compression.
- Sidechain type External is not routable in dawd yet (no sidechain edges) — stay on Feed-forward.
