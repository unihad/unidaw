LSP Limiter Stereo — transparent brickwall limiter with oversampling and dithering.

- Threshold is a linear factor (0.89 ≈ -1 dB); Input gain drives into it. Oversampling "True Peak/…" for true-peak safe output; Dithering only on the final export to 16 bit.
- Operating mode: Herm Thin/Wide/Tail (smooth), Exp/Line variants — Herm Wide is a safe default. Lookahead, Attack / Release time in ms.
- For quick master limiting dawd's own Limiter (dB parameters, at: "master") is simpler; use LSP when you want the oversampling/dither options.
