LSP Gate Stereo — noise gate: closes below a threshold; cleans drum mics, tightens tails.

- Curve threshold (= open threshold) and Reduction (how much the closed gate attenuates) are linear factors; Attack / Release / Hold time in ms. Hysteresis on adds a separate close threshold against chatter.
- Gains are linear factors, not dB (1 = 0 dB, 0.5 ≈ -6 dB, 2 ≈ +6 dB); thresholds likewise (0.25 ≈ -12 dB, 0.1 = -20 dB) — listParameters shows them only in the text (real is just 0–1), so set them by text: setParameter {name, text: "0.5"}.
- Sidechain High-/Low-pass filter mode lets e.g. only the kick's band open the gate.
