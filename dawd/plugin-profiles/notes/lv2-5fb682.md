LSP Parametric Equalizer x8 Stereo — 8-band parametric EQ (bells, shelves, cuts, slopes per band).

- Bands are off by default (Filter type n = Off). Set the type first, then Frequency n, Gain n, Quality factor n — Frequency defaults to 16 Hz and Gain to 0 dB, so a band does nothing until all three are set.
- Gains are linear factors (Gain n: 1 = 0 dB, 2 ≈ +6 dB, 0.5 ≈ -6 dB) and shown only as text — set by text: setParameter {name: "Gain 0", text: "2"}.
- All filter types work (Bell, Hi-/Lo-pass with Filter slope x1–x4, shelves, Notch …); set Filter type n by text ("Lo-pass").
- 103 parameters, many display-only (FFT graph, Hue, Inspect): pluginInfo with paramQuery ("0", "gain") narrows. For simple tone shaping x42-eq is quicker.
