# Decisions zu agent-daw stehen im Repo

- **Status:** gilt
- **Datum:** 2026-10-24, Matthias

## Kontext

Bis 2026-10-23 lagen die Decisions zu dawd in einer internen Wissensablage
außerhalb des Repos. Claude Code hat keinen Zugriff darauf; Agents im
Repo konnten Decisions weder lesen noch nachtragen.

## Entscheidung

Alle Decisions zu agent-daw werden im Repo festgehalten, unter
`docs/decisions/` (Format in `README.md` dort).

## Folgen

- Neue Decisions schreibt der Agent, sobald Matthias entschieden hat.
- Die älteren Decisions gelten weiter und sind in `README.md`
  aufgelistet, bis eine Repo-Decision sie ersetzt.
